Conjurer: Repackaging with WIX

Conjurer

Conjurer is a new way to repackage applications. The WIX toolset has been the first choice for creating/managing and maintaining MSI's for some time now. Conjurer takes advantage of this technology to generate quality MSI's. With Conjurer, you don't just end up with an opaque, complicated MSI table structure, requiring a proprietary and expensive editor to customize. Conjurer generates the WIX files and provides a build system, that allows you to edit and maintain the MSI for multiple clients, and into the future. Take advantage of source control, versioning, structured hierarchical layout, and free editors/build tools to keep repackaging costs down, without compromising on power and flexibility, all through the use of WIX.

See the benefits of WIX here.

Conjurer can be used by developers to bootstrap their WIX development efforts, or professional repackaging shops to generate top quality, maintainable WIX build systems, for the best MSI output.

Features

  • Snapshot an application once. Customize many times.
  • Uses WIX, the preferred installation build technology of Microsoft and many other premiere software companies.
  • The Conjurer toolchain is built for packaging shops, allowing team customization of snapshot exclusions, rules for package naming.
  • WIX can have aa steep learning curve for developers. Conjurer provides a good starting point to bootstrap your WIX build system.

Snapshot Once, Build Many Times

Once you have a snapshot of an application stored on the network, you can go back and customize that installation as many times as you need, for example for different clients, or to include or exclude different parts of the product. The snapshot contains everything that changed on the machine, and this is always available. If stored on the network, it is not discarded with the snapping machine. So once you have a good snapshot, you never have to snap the application again. It's in the customization and the build process that you exclude items. This requirement to only snapshot the application once can save significant time and money across many packaging projects.

All the advantages of the WIX toolset.

The days of hugely expensive MSI editors are past. WIX is the future of MSI production, and has been for some time. WIX utilizes xml files as input allowing:

  • Source control
  • Use your favourite XML editor
  • Modular construction of large MSIs
  • Reusable fragments
  • Hierarchical and intuitive data constructs
  • Many free plugins to support db creation, IIS website management, customized GUI's, and many others

Designed for large packaging shops.

Large packaging shops require shared resources, settings, and quality criteria in order to provide consistent quality. With Conjurer, exclusion sets can collaboratively be built up and shared between team members. Settings and quality criteria such as naming standards can be centrally managed.

Bootstrap your WIX build system.

Software developers wanting to release their software can face a large time barrier in working out how to set up a WIX build system. Conjurer can be used to capture the changes their software needs to make to the machine, and generate a WIX build system that they can maintain and expand upon.
